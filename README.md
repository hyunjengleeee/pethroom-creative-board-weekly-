# 페스룸 주간 소재 리포트

광고 소재를 매주 분석해서 **대표님·제작자 모두** 보는 보드입니다. 링크만 있으면 누구나 볼 수 있어요.
실시간 숫자는 기존 [소재 담당자 보드](https://pethroomus.vercel.app/)에서 보고, 이 보드는 주 단위 정리와 다음 주 제작 방향을 봅니다.

## 구조

| 경로 | 역할 |
|---|---|
| `public/index.html` | 화면 (주차 선택 · 요약 · 위닝/부진 소재 · 공통점 · 제작 가이드 · 랜딩 제안 · 특징별 성과) |
| `public/data/` | 주차별 데이터 (`index.json`, `week-YYYY-MM-DD.json`) — 스크립트가 만듦 |
| `public/thumbs/` | 소재 썸네일 (메타 이미지 주소는 며칠 뒤 만료돼서 받아 둠) |
| `scripts/build_week.py` | 시트 → 주간 데이터·썸네일 만들기 |
| `scripts/sheet_write.py` | 소재 태그 · 주간 분석 글을 시트에 쓰기 |

서버 코드나 Vercel 환경변수가 없어요. GitHub에 올라온 파일을 Vercel이 그대로 보여줍니다.

## 시트 탭 (★ 페스룸_메타_클로드)

- **소재태그**: 소재별 특징 (포맷 · 이미지 문구 · 문구 각도 · 모델·견종 · 비포애프터 · 배지 · 할인 · CTA). Claude가 이미지를 보고 채우고, 사람이 고쳐도 됩니다.
- **주간리포트**: 주차별 한 줄 요약 · 잘된/안된 공통점 · 다음 주 제작 가이드 · 랜딩 제안. 칸 안에서 줄바꿈하면 항목이 나뉩니다. `상태`를 `확정`으로 바꾸면 보드의 "초안" 표시가 "확정"으로 바뀝니다.

## 매주 하는 일 (자동)

1. `python scripts/build_week.py --pending` → 태그 없는 소재 목록과 이미지
2. 이미지를 보고 태그 → `python scripts/sheet_write.py tags 파일.json`
3. 지난주 숫자를 보고 분석 글 → `python scripts/sheet_write.py report 파일.json`
4. `python scripts/build_week.py` → `git push` → Vercel 자동 배포

시트를 직접 고친 뒤 보드에 반영하려면 4번만 다시 하면 됩니다.

## 기준

- 주차: 월~일 (메타 계정 날짜 기준)
- 위닝: 그 주 지출 $20 이상 · ROAS 50% 이상 · 주문 2건 이상, 매출 순 / 부진: 지출 $20 이상 · ROAS 25% 미만
- 아마존 데이터가 아직 없는 주는 CPL로 임시 판단
- 특징별 성과: 시작부터 그 주 끝까지 누적, 지출 $20 이상 쓴 소재만
